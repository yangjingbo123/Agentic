# Baseline definitions used in this repository

## Shared controls

Trainable credit-assignment baselines reuse the production four-role rollout,
blackboard, SFT initialization, optimizer, frozen SFT KL reference, PPO clipping,
sampling budget, and MATH/AIME evaluation. The existing RACA source and regular
training entry point are not modified or rerun.

## Credit assignment

### Multi-Agent Outcome GRPO

For the `N` rollouts of one question, standardize terminal correctness and
broadcast that trajectory advantage to every generated turn.

### Role-Wise Reward GRPO

Use simple local supervision: answer correctness for proposer outputs, binary
error-detection correctness for critics, score calibration for verifiers, and
terminal correctness for controllers. Normalize by role and primary/response
status. No RACA interaction reward, causal window, correctness layer, or token
channel is used.

### AT-GRPO-Adapted

Combine global terminal correctness and local role reward with
`team_weight=1.0`, then normalize among actions generated by the same role and
role-local turn index. The production complete-workflow sampler is retained, so
this is reported as an adaptation rather than an exact reproduction of the
Stronger-MAS tree sampler.

### GiGPO-Adapted

Add a question-level macro GRPO advantage and an exact-anchor micro advantage.
The anchor hashes the full generation prompt. Step return uses sparse terminal correctness propagated backward with $\gamma=1$.
Because free-text blackboard prompts rarely repeat exactly, exact anchor coverage
is a mandatory diagnostic. A coarse structured anchor implementation exists for
measurement only and is disabled in the approved configuration.

## System-level baselines

- **SFT-CoT:** one greedy proposer trajectory.
- **Single-Agent GRPO:** proposer-only outcome GRPO.
- **Self-Consistency:** `N=8` sampled proposer trajectories; answers are grouped
  using the project mathematical-equivalence grader and majority-voted.
- **Self-Refine:** initial answer, same-adapter feedback, one revised answer.
- **Fixed Four-Role (SFT):** proposer, controller, critic, proposer correction,
  verifier; routing is fixed and the corrected answer is returned.
- **Fixed Four-Role + Outcome GRPO:** the same fixed pipeline trained with shared
  terminal correctness.
